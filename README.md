# 📊 Marks Normalizer (Streamlit App)

A simple web app built using **Streamlit** to calculate a student's **normalized score** based on class performance.

---

## 🚀 Overview

This app helps you convert your raw marks into a **normalized score out of 50**, considering:

- Your marks
- Maximum marks in the class
- Minimum marks in the class

---

## 🧠 Formula Used

Normalization is calculated as:

Normalized Score = ((Marks - Min) / (Max - Min)) × 50

This scales your performance relative to your class.

---

## ⚙️ Features

- 📥 User-friendly input fields
- ⚡ Instant calculation
- 📊 Output displayed as a metric
- ❗ Error handling for invalid inputs
- 🧾 Clean UI using Streamlit
